# Vaihingen 多模态离职交接（2026-11-13）

## 当前结论

当前值得继续的起点是输入级 IRRG+DSM，而不是直接重复 HeightSelective 两轮。

| 方法 | OA | mF1 | mIoU | DSM 对照 |
|---|---:|---:|---:|---|
| 论文单模态 | 93.28 | 91.31 | 84.31 | 不适用 |
| 输入级 IRRG+DSM | 91.09 | 90.41 | 82.70 | 未通过，+0.001 pp |
| 四层特征融合 | 90.16 | 89.34 | 80.96 | 未通过，-0.019 pp |
| HeightSelective stage 1 | 90.71 | 89.78 | 81.68 | 通过，+0.552 pp |
| HeightSelective stage 2 | 90.71 | 89.85 | 81.79 | 通过，+0.531 pp |

输入级模型的绝对精度最高，但正常 DSM 只比全零 DSM 高 `0.0011` 个百分点，说明其增益不能归因于第二模态。HeightSelective 证明了网络确实利用 DSM，但主干/解码器状态较弱。下一版应取输入级权重中的 `segmenter` 作为光学初始化，并采用 HeightSelective 的结构化高度注入思想。

## 回学校后的第一件事

1. 克隆仓库并下载 Release 中的 `input_fusion_best_model.pt` 与 `height_selective_stage2_best_model.pt`。
2. 按 `SHA256SUMS` 校验权重；重新放置 Vaihingen 数据，不要从 GitHub 获取数据集。
3. 用输入级权重跑一次原始测试配置，要求 mF1 与 `90.4071` 相差不超过 `0.01` 个百分点，确认环境、类别映射和 TTA 一致。
4. 运行正常/置零/打乱 DSM 诊断，再开始改结构。

## RTX 3090 下一轮实现

只实现一个混合方案，避免同时改太多变量：

- 核心：加载 `InputFusionRoGLSNet.segmenter` 的全部权重；旧输入门控只用于复现实验，不假定它有效。
- DSM 表示 A：保留原始 DSM 的训练集统计标准化，用于对照旧输入门控。
- DSM 表示 B：完整区域 `5%–95%` 截断到 `[0,1]`，提取坡度、局部高差和边缘。
- 注入点：结构 DSM 只修正 RoAFM 的 value 和分类 logits，不修改光学 q/k，不再对 CDFormer 四层无差别相加。
- 初始化：所有新增残差头零初始化并限制幅度，epoch 0 必须严格复现输入级权重结果。

训练顺序：

1. 前 10 个 epoch 冻结输入级核心，只训练结构 DSM 编码器和残差头。
2. 随后只解冻原解码器与新增分支约 40 epoch；CDFormer 先保持冻结。若平台期明显，再用 `1e-5` 解冻最后两层。
3. 3090 先预检 micro-batch 4、累积 2；OOM 才回退到 2、累积 4。有效 batch 始终为 8。
4. 继续输出每轮 `history.csv/json`、`live_status.json` 和每 5 轮覆盖的续训断点。

## 硬验收门槛

- epoch 0：复现输入级 mF1 `90.4071`，误差不超过 `0.0001`（比例值）。
- 正常 DSM：mF1 至少比零 DSM、打乱 DSM 中较高者高 `0.002`。
- 第一目标：D4 mF1 高于输入级 `90.41`。
- 论文目标：OA/mF1/mIoU 达到 `93.28/91.31/84.31`。
- 任一模型的报告必须标明无 TTA 选择指标与最终 D4 指标，不能混用。
